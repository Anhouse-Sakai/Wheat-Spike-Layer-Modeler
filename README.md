# Wheat Spike-Layer Modeler

Wheat Spike-Layer Modeler is a multilingual wheat simulation model generator for Windows 64-bit and macOS.

小麦穗层模型生成器是一款支持 Windows 64 位与 macOS 的多语言小麦模拟模型生成工具。

小麦穂層モデル生成器は、Windows 64-bit と macOS に対応した多言語の小麦シミュレーションモデル生成ツールです。

Download the packaged applications from the repository's **Releases** page.

请从仓库的 **Releases** 页面下载安装包。

パッケージはリポジトリの **Releases** ページからダウンロードできます。
