# Wheat Spike-Layer Modeler — Windows 版

**言語：日本語**

## 動作環境

- 64 ビット版 Windows 10 または Windows 11。
- システムの Microsoft Edge WebView2 を使用します。Electron や Chromium を同梱していないため、アプリケーションは軽量です。

## 起動方法

1. `Wheat_Spike_Layer_Modeler_Windows_64bit_v1.5.zip` をすべて展開します。
2. 展開先のすべてのファイルと `web` フォルダーを同じ場所に保持します。
3. `Wheat Spike-Layer Modeler.exe` をダブルクリックします。

`.exe` だけをコピーしないでください。実行には `WebView2Loader.dll` と `web` フォルダーの両方が必要です。

本アプリケーションには商用コード署名証明書がありません。SmartScreen に「不明な発行元」と表示された場合は、ZIP ファイルの入手元が信頼できることを確認してから、「詳細情報 → 実行」を選択してください。

## WebView2 Runtime

Windows 11 には通常 WebView2 Runtime がプリインストールされており、ほとんどの Windows 10 PC にもインストールされています。起動時に Runtime が見つからないと表示された場合：

1. ダイアログから Microsoft の公式ダウンロードページを開きます。
2. Evergreen WebView2 Runtime をインストールします。
3. 本ソフトウェアをもう一度起動します。

公式ダウンロードページ：<https://developer.microsoft.com/microsoft-edge/webview2/>

## キャンバスと解像度

- キャンバスのアスペクト比は `16:9`、`4:3`、または「カスタム」から選択できます。
- カスタムモードでは、キャンバスの幅と高さを px 単位で直接入力できます。
- PNG の解像度は、キャンバスと同じ、1920 px、2560 px、3840 px、またはカスタムから選択できます。
- カスタム PNG の幅または高さを変更すると、もう一方がキャンバスの比率に合わせて自動調整されるため、植物が引き伸ばされることはありません。

## モデリングと複数個体の比較

1. 材料名、PH、HSH、LSH、および TSB、MSB、BSB の穂数と平均穂長を入力します。
2. 高さと穂長の単位はすべて cm です。
3. 図の右上にある `+` をクリックすると新しい個体を追加できます。すべての個体は `0 cm` の基準線と高さ目盛を共有します。
4. 「編集中の個体」で 1、2、3……番目の個体を選択し、それぞれのパラメータを個別に変更します。
5. モデル化したコムギを一時保存、読み込み、削除できます。最大 100 個のモデルをキャッシュできます。
6. CSV/TSV データをインポートして一括入力できます。

## 内蔵サンプル

- 「全サンプル / C / L を読み込む」をクリックすると、同じ高さ目盛上に 3 つの平均コムギモデル（All samples、Cultivar (C)、Landrace (L)）が追加されます。
- サンプルの高さと穂長には元の平均値を使用し、穂数はソフトウェアで必要な整数に四捨五入されます。
- 3 個体には異なる種子形状が使われており、引き続き個別に選択・編集できます。

## 図中テキストのカスタマイズ

- プレビュー上部の「図中テキスト」を展開すると、タイトル、サブタイトル、縦軸タイトル、フッター、および TSB、MSB、BSB、PH、HSH、LSH の表示内容をリアルタイムで変更できます。
- タイトル、サブタイトル、軸タイトル、目盛、SB 注釈、形質マーカー、フッターの文字サイズを個別に調整できます。
- タイトルとサブタイトルでは、`{name}`、`{ph}`、`{hsh}`、`{lsh}`、`{spikes}`、`{belt}`、`{seed}`、`{current}` のプレースホルダーを使用できます。
- 図中のフォントは Times New Roman です。テキスト設定はローカルに自動保存され、プレビュー、SVG、PNG に適用されます。
- 材料名は左側で個体ごとに設定できます。「テキストを初期設定に戻す」をクリックすると、すべての設定を復元できます。

## 画像の保存

- 「現在の個体 SVG/PNG」は、現在選択されている個体だけを保存します。
- 「全個体を結合 SVG/PNG」は、キャンバス上のすべての個体と共通の高さ目盛を保存します。
- エクスポートされるのはコムギのプレビューキャンバスだけです。パラメータパネル、テキスト編集欄、ボタン、ページの余白は画像に含まれません。

- 保存ボタンをクリックすると、Windows のファイル保存ダイアログが表示されます。

## キャッシュとプライバシー

- 本ソフトウェアはオフラインで動作し、材料データをアップロードしません。
- コムギモデルのキャッシュは `%LOCALAPPDATA%\WheatSpikeLayerModeler\WebView2` に保存されます。
- このディレクトリを削除したり、アプリのデータを消去したりすると、キャッシュが削除される場合があります。重要なデータは CSV/TSV ファイルとしても保存してください。
